# 🐍 python_grind

**Learning Python from scratch — one day, one concept, one practice set at a time.**

This repository is my daily Python learning log. It starts from the absolute basics and works its way up through control flow, data structures, OOP, exception handling, and file I/O — with dedicated practice sets along the way to actually cement what's learned, not just read about it.

##  Why This Repo Exists

Most learning gets lost without practice. This repo is my way of staying consistent — covering one Python topic, then immediately reinforcing it with a hands-on practice set before moving to the next. It's less about finishing fast and more about building a solid foundation, topic by topic.

---

##  Getting Started

Clone the repo and explore any folder directly:

```bash
git clone https://github.com/deepanshu-bisht-dev/python_grind.git
cd python_grind
```

Each numbered folder is self-contained — just open it up and run the `.py` files inside with:

```bash
python filename.py
```
